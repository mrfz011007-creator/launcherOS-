# LauncherOS Evidence

This directory stores durable verification references.

## Evidence levels

1. implementation evidence;
2. Git diff/checkpoint;
3. build/test evidence;
4. automated verification;
5. actual device/runtime evidence;
6. Project Owner acceptance.

## Rules

Build success alone does not prove product acceptance.

For LauncherOS visual work, device screenshots/video or equivalent runtime evidence may be required when the acceptance criteria depend on visual behavior.

Do not store secrets or credentials.
